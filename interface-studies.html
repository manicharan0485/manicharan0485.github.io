    Neumorphism

    Machine Monitor

    An Industry 4.0 control panel for a production line, inspired by my automation internship at RWTH Aachen.

    Linie 2 · Halle BAachen plant · early shift 06:00–14:00

    3 of 3 machines running
    Shift output
    OEE (overall equipment effectiveness)0 %

    Why soft UI

    Neumorphism imitates physical controls, which suits a panel that sits next to real machines. I kept labels and the blue active state strong, because pure soft UI is known for weak contrast.

    Try it

    Switch a machine off, or drag the speed slider. The gauge, temperature, output and OEE all follow.

    Built with

    ReactPython (FastAPI)MQTT / OPC UAWebSocketsDocker

      Admins live in the shell, so this concept leans into it. Amber phosphor, scanlines and function-key labels give the screen character, while the commands and output stay real and readable.

        Aurora
        AI Agents Console
        
      
        A control room for Claude-powered agents that handle IT work: triaging tickets, cutting cloud costs, planning patches and reading logs. Risky actions wait for a human to approve them.
        
    
        
    
        
      
        
        
        AI Agents
        
        
        Runs today 128
        Success 96 %
        Avg cost €0.04 / run
        Waiting for you 1
        
      
        
      
        
        
        
        
        
          
        
          
        
          
          
          
          
          
          
        
          
      
          
    
          
    
          
      
          Why aurora
          AI tools can feel like a black box. Soft light gradients keep the console calm, and the agent's every step (thinking, tool call, result) is laid out as a readable timeline, so people can trust what it did.
          
      
          Try it
          Approve or reject the waiting patch plan. Pick another agent, choose a suggested task or type your own, and watch it run. Runs are scripted for this demo.
